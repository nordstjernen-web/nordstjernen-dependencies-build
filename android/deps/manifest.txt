# --- Media (video / audio codecs) -------------------------------------------
# The open-web media stack the engine needs to decode <video>/<audio>: the same
# royalty-free codecs Firefox vendors in mozilla-central (media/libdav1d,
# media/libopus, media/libogg, media/libvorbis). Firefox pins these to specific
# upstream revisions; we pin the latest upstream *stable release* (>= Firefox's
# revision in every case, so we carry its security fixes). Codecs are the browser
# attack surface most exposed to hostile input, hence exact version + sha256
# pins. libvpx (VP8/VP9) is built too, by a bespoke recipe for its ffmpeg-style
# configure (see its entry below).
#   ogg     -> container framing        (dav1d/opus/vorbis are the codecs)
#   vorbis  -> Vorbis audio  (needs ogg; find_package(Ogg) resolves in-prefix)
#   opus    -> Opus audio    (WebM/Ogg; OPUS_HARDENING stays on by default)
#   dav1d   -> AV1 video decode (Firefox's AV1 decoder; decode-only by design)
#   vpx     -> VP8/VP9 video decode (Firefox media/libvpx; decode-only, static)
